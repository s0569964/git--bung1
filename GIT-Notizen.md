GIT ist eine Software , der Team Arbeit erleichtert.



\## Wozu ist Versionsverwaltung nützlich?



• Vor Git: Man musste Projektordner manuell kopieren und umbenennen (z. B. Projekt\_v1, Projekt\_final, Projekt\_final\_KOPIE).

• Mit Git: Es gibt nur noch einen einzigen Projektordner. Git speichert den gesamten Verlauf im Hintergrund. Sie können per Befehl zu jedem beliebigen Zeitpunkt in der Vergangenheit zurückspringen.
